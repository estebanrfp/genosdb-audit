# Release Status

**v0.1.0: public preview of the defensive CLI. Not a production security certification.**

## Included

- English CLI and documentation.
- GenosDB target schema, read-only artifact hashing and receipt consistency checks.
- A 16-family Zero Trust obligation catalog.
- Passive official CDN latest resolution and version-pinned artifact fingerprints.
- Offline synthetic tests and a read-only GitHub Actions test workflow.
- MIT license for this repository's code.

## Deliberately Excluded

The local browser campaign runner, packet injection tools, vulnerability reproduction scripts, raw evidence, development proposals, test identities, and GenosDB distribution/source files remain outside this repository. This is not a repackaging of the complete private laboratory.

## Historical Validation Boundary

A local campaign recorded 52 PASS. A later saved campaign recorded **51 PASS, 1 FAIL, 0 INCONCLUSIVE**, with a failing `role-replay` assertion. Its cause has not been independently resolved; the result alone does not establish a GenosDB vulnerability. Neither historical campaign is presented as verification of this public release.

The public reviewer has not independently reproduced or explained that discrepancy. No claim of exhaustive coverage, protocol correctness, or impenetrability is made. Offline reviewer tests and passive CDN fingerprints do not close it.
